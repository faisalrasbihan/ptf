# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful place for people to collaborate. We pledge to make participation in this project harassment-free for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, sexual identity and orientation, or technical background.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, and ask clarifying questions before escalating.
- Give feedback about code and ideas, not personal worth.
- Accept maintainer decisions gracefully.
- Be especially careful with claims about financial forecasting, model performance, or investment usefulness.

## Unacceptable behavior

- Harassment, intimidation, stalking, or sustained disruption.
- Insults, personal attacks, or demeaning comments.
- Sexualized language or imagery.
- Publishing private information without explicit permission.
- Promoting this project as financial advice or encouraging users to treat forecasts as trading recommendations.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block users, or take other action they judge necessary to keep the project healthy.

If you experience or witness unacceptable behavior, contact a maintainer privately. If this repository is hosted on GitHub and private vulnerability or abuse reporting is enabled, use that channel when appropriate.
